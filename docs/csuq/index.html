When to use it

Surveys of people using a system in their own work, outside the lab. Use PSSUQ for lab studies.

How it is scored

  1. Each subscale and the overall score are the mean of the answered items (N/A is skipped).
  2. Overall uses all 16 items; item 16 only contributes to the overall score.
  3. Scores are also rescaled to 0–100 with ((mean − 1) / 6) × 100, which Lewis (2018) showed lines up closely with SUS.
  4. This version uses 1 = strongly disagree so that higher is better, as in Lewis (2018).

Frequently asked questions about the CSUQ

How do I calculate the CSUQ score?

  1. Each subscale and the overall score are the mean of the answered items (N/A is skipped).
  2. Overall uses all 16 items; item 16 only contributes to the overall score.
  3. Scores are also rescaled to 0–100 with ((mean − 1) / 6) × 100, which Lewis (2018) showed lines up closely with SUS.
  4. This version uses 1 = strongly disagree so that higher is better, as in Lewis (2018).

This calculator applies these steps automatically as soon as every item is answered.

What is a good CSUQ score?

Higher is better in this version. Rescaled to 0–100, CSUQ scores sit close to SUS scores, so around 68 is average.

How long does the CSUQ take?

The CSUQ has 16 items and takes about 5 minutes. Typical use: Surveys of people using a system in their own work, outside the lab. Use PSSUQ for lab studies.

Can I calculate CSUQ scores for many participants at once?

Yes. Collect the answers in Excel, Google Forms, Qualtrics or any other tool with one row per participant and columns Q1 to Q16, then upload the table as CSV or JSON on the "Score a dataset" tab. If participants filled in the CSUQ here and sent you their downloads, drop all the PDF, CSV, JSON or ZIP files in at once instead. You get a score for every person, plus the mean, standard deviation and 95% confidence interval.

What is similar to the CSUQ?

Similar questionnaires include Post-Study System Usability Questionnaire (PSSUQ), System Usability Scale (SUS), Usability Metric for User Experience (UMUX).

Similar questionnaires

PSSUQ

Post-Study System Usability Questionnaire Validated

The lab-study counterpart of CSUQ (version 3, 16 items). Comes with published norms for each subscale.

16 items 5 min 7-point scale
SUS

System Usability Scale Validated

The most widely used usability questionnaire. Ten alternating items, scored 0–100 and graded against a large normative database.

10 items 3 min 5-point scale
UMUX

Usability Metric for User Experience Validated

Four items aligned with the ISO 9241-11 definition of usability. Designed to correlate closely with the SUS.

4 items 1 min 7-point scale
