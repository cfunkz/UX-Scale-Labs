How it is calculated

  1. Each file is matched to its questionnaire from the details saved in it. JSON, CSV and TXT downloads are read directly. PDFs carry the raw answers inside the file; PDFs from older versions of the site only hold the printed report and are listed as skipped.
  2. Every person is scored with the same code as the questionnaire’s own calculator, including reverse-scored items and N/A answers.
  3. The same answers saved in several formats, such as the four files in one ZIP, are counted once. Two different results with the same participant label are both kept, the second marked “(2)”.
  4. Group results show the mean with a 95% confidence interval based on the t distribution (Sauro & Lewis, 2016). NPS groups show the Net Promoter Score instead.
  5. The dataset download uses the same layout as the calculators’ dataset templates, so it can be opened in Excel, SPSS or R, or uploaded again later.

References

  1. Sauro, J., & Lewis, J. R. (2016). Quantifying the User Experience: Practical Statistics for User Research (2nd ed.). Morgan Kaufmann.

Frequently asked questions

Which files can I upload?

Any result downloaded from a questionnaire page on this site: PDF, JSON, CSV, TXT, or the ZIP that holds all four. You can mix formats and questionnaires in one go. Files from other tools are skipped and listed so you can check them.

How do I collect results from participants?

Send each participant the link to the questionnaire, for example the SUS calculator. Ask them to enter their participant ID, finish the questionnaire and send you the download. JSON or CSV are the safest formats to ask for.

Why was a PDF skipped?

PDFs from older versions of the site only contain the printed report, not the answers in a form a computer can read. Ask for the JSON or CSV version of those results, or type the answers into the dataset template.

What happens to people who filled in more than one questionnaire?

Each questionnaire gets its own group, and a by-participant table lines up their scores side by side. Scores are matched on the participant label, so ask people to use the same code every time.

Are my participants’ files uploaded anywhere?

No. The files are opened by your browser and never leave your computer. Closing the tab clears everything.
